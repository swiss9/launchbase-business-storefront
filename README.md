# LaunchBase

A premium, no‑code website template for businesses — ready to launch in minutes.

---

## Quick start

1. Click **Use this template** on GitHub to create your own copy.
2. Clone your new repo, then run `npm install` and `npm run dev`.
3. Deploy to **Vercel** or **Netlify** (click the button below).

[![Deploy to Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fswiss2099%2FLBS)
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/swiss2099/LBS)

---

## What you get

- A beautiful public storefront with product cards and instant chat booking (WhatsApp, Telegram, Discord, Viber).
- Star ratings and dedicated review pages for every product.
- A secure admin panel to manage products, reviews, and business details — without code.
- Admin management: the first admin can promote or remove other admins from the dashboard.
- Automatic admin creation: the first person who signs up becomes the owner.
- A clean, responsive design that works on mobile, tablet, and desktop.
- Zero‑cost stack: Next.js (free hosting) + Supabase (free database tier).

---

## After you deploy

Follow the **SETUP.md** guide in your repository to connect your own Supabase database.  
It shows you how to get your API keys, run the migration, and turn off email confirmation.

Once connected, sign up on your live site — you’ll instantly become the admin.  
Visit `/admin` to manage your store.

---

## Customizing the booking button

The product cards show **“Order via Chat”** by default.  
To change it, open `src/components/ProductCard.tsx` and edit the button text on line 182.

Common alternatives: `Book Now`, `Inquire`, `Chat with Us`, `Buy Now`.
